Detailed Description

The list infrastructure that can hold one datacast object per datatype known to the current C infrastructure of libdsC. It is reachable with static access to dc_functions. @note However, since this is astatic struct, it is plausible, thus, that if more than one library of the project useslibdsC, all generaldatacastpointers of all using libraries are part of the member arraydc_functions->dc`.
