Detailed Description

Implements the general data type of libdsC

Author
N. Devillard

This module implements a simple generic data type object, since data is provided in many different ways, structs, classes and read-methods.

typedef struct _datatype_ datatype

The general datatype struct of libdsC. It can save whatever struct/class of your choice at it's member void* vars.

Note
Function pointers can be altered on initialization to have the correct behaviour and ease-to-use functions at developers sight.
