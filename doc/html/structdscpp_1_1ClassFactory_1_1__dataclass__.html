Detailed Description

The C++ generic type of data classes for e.g. use in inheritance of other libraries or parts of the dsC++API.

Note
Adds an attribute of the type std::type_info type_data that thus can be used for e.g. type casting a ClassFactory::DataClass dc basing and inheriting type like this

return static_cast<decltype(std::declval(std::type_index(dc.type_data).name())) *>(dc.data);

Note
You may use ClassFactory::castData() for conversion of the ClassFactory::DataClass::data attribute
