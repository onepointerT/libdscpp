Detailed Description

template<typename Key, typename T, class Compare = std::less<Key>>
class dscpp::Map< Key, T, Compare >

This is a default std::map< Key, T, Compare > with some additional functions.

Template Parameters
KeyThe key value's type, e.g. std::string; no const
TThe type to save as elements for the dscpp::Map
CompareHow to compare the elements on such things like sorting, merging and similar. Defaults to std::less< Key > and is optionally omittable
