Detailed Description

This struct implements a basic void pointer struct with datatype naming for further use on difficult-to-predict generic data formats on a lower backend api that thus can be casted to own datatypes.

Note
Function pointers can be altered on initialization to have the correct and ease-to-use cast function at developer's near distance.
