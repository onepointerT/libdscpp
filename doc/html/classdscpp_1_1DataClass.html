Detailed Description

template<class InheritingClass, class DataType>
requires dscpp::is_datatype< DataType >
class dscpp::DataClass< InheritingClass, DataType >

The feature-enabling data class for data types of libdsC/libdsC++.

Template Parameters
InheritingClassThe class adding all functionality to DataType. OwnDataClass is a base class of InheritingClass
DataTypeThe self-designed data type, that has ClassFactory::DataType as its base class and is derived from dscpp::Datatype<DataType>
